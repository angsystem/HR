# ANG HR v0.6.0 功能基準 ## 入口與外觀 | 模組 | 基準要求 | 包內位置 | |---|---|---| | 日光／暗夜 | 背景、主題、開場影片、手動切換、記住選擇 | `src/`、`deploy/`、四個 media 檔 | | 標準／Lite | 同一套功能，只降低渲染成本；支援 `?mode=lite` | `display-mode.js/css`、React App | | 入口 | 員工、企業、Personal、Free、方案卡與驗證入口 | `src/main.jsx`、`index_connected.html` | | 全面改名 | 全套統一為 ANG HR 命名 | 全包文字掃描通過 | ## 身分與公司 | 模組 | 基準要求 | |---|---| | 管理註冊 | Email OTP、Google、LINE；驗證後建立公司與方案 | | 員工開通 | 一次性連結／開通碼／QR，綁定 `device_id` | | Token | 7 天、啟動換新、最多重試 5 次；後端驗證，不信任前端角色 | | 多公司 | `company_id` 隔離；同一人可加入最多 3 間公司 | | 換設備 | 管理員撤綁後重新開通 | | 角色 | Creator、Owner、Admin、Manager、Supervisor、Employee | ## 排班與選休 | 模組 | 基準要求 | |---|---| | 週選休 | 可設定開放日、截止日、發布日、最多選休天數 | | 月選休 | 支援 28–31 天月份、起訖、截止、發布與員工端同步 | | 班別 | A 08–16、B 08–12、C 13–19、D 08–19，可由管理端設定 | | 鎖定 | 已發布週期不可由員工修改，異動走審核 | ## 打卡 | 優先順序 | 行為 | |---|---| | 1. NFC | Android 原生讀取 UID/NDEF；後端比對 NFC key、裝置與定位 | | 2. QR | 掃描分店 QR；後端比對 QR key、裝置與定位 | | 3. GPS 按鈕 | 驗證打卡點座標、半徑、accuracy 與伺服器時間 | | 4. 手動 | 不直接寫入出勤，建立待審核補打卡申請 | 共通規則： - 15 分鐘內相同類型禁止重複送出。 - 分店可設定多個打卡點。 - 支援指派在有效期間自動增加臨時打卡點。 - 支援點可設定起訖、半徑、分店與是否保留原店打卡資格。 - 裝置不符時拒絕，不能只相信手機時間或前端判斷。 ## 人員、審核與薪資 - 手機、Email、緊急聯絡人為必填。 - 關係選「其他」才顯示自訂欄位。 - 緊急聯絡人變更保留歷史，不覆蓋舊資料，查閱留稽核紀錄。 - 請假、補卡、資料上傳、留言與薪資可設定多層審核。 - 薪資規則：8 小時內基本時薪、8–10 小時 1.34、超過 10 小時 1.67；正式計算仍須依公司與法規設定驗證。 ## Android - NFC 前景掃描事件：`ANG_HR_NFC_SCAN` - 定位事件：`ANG_HR_LOCATION` - 深層連結事件：`ANG_HR_DEEP_LINK` - 原生就緒事件：`ANG_HR_NATIVE_READY` - `device_id`：Android Secure ID - 原生 QR 掃描事件：`ANG_HR_QR_SCAN` - 相機／檔案選擇、通知、外部 OAuth、`anghr://auth` 返回 - App 預設進入 `index_connected.html`，使用正式 GAS 身分流程
